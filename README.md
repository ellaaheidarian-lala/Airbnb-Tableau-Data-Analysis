# Airbnb Listings Data Analysis (Tableau Project)

A data visualization and business intelligence project analyzing the 2016 Airbnb dataset to uncover insights regarding property listings, pricing trends, and accommodation features.

##  Project Overview
This project explores the Airbnb listings dataset using **Tableau Public** to build an interactive and analytical dashboard. The main objective is to examine property pricing patterns, room types, and neighborhood distributions to understand short-term rental market dynamics.

##  Tools & Techniques Used
* **Software:** Tableau Public
* **Data Prep & Modeling:** Excel dataset connection (`Listings` table integration)
* **Data Transformation:** 
  * Created custom **Calculated Fields** (e.g., price per guest metrics).
  * Implemented data organization and quick table calculations.
* **Data Visualization & Design:**
  * Bar charts and distribution graphs.
  * Color coding and custom labeling via the Marks card.
  * Interactive filtering for neighborhood and room types.

##  Key Visualizations & Insights
* **Price Distribution:** Analyzed how listing prices vary across different types of accommodations.
* **Interactive Filters:** Enabled dynamic exploration by neighborhood and property characteristics to help users query specific criteria.

##  How to View/Use
1. Download the packaged Tableau workbook file: `[Airbnb-Analysis-Project.twbx]`
2. Open the file in **Tableau** (Desktop or Tableau Public) to interact with the dashboard, filters, and underlying calculations.
